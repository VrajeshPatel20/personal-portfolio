# Personal Portfolio

Vrajesh Patel - Senior Data Engineer Portfolio Website

## Deployment

This project is configured for Vercel deployment.

### Deploy to Vercel

1. Push your code to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Import your repository
4. Vercel will automatically detect this as a static site and deploy it

### Local Development

Install dependencies:
```bash
npm install
```

Run local server:
```bash
npm run dev
```

The site will be available at `http://localhost:3000`
